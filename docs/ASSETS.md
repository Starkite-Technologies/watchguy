# Original visual assets

Created with the built-in `image_gen` tool (not the API/CLI fallback). Outputs were inspected and optimized to WebP for this project. No third-party product photographs were scraped or relabelled.

These are original **unbranded concept visuals**, not images of real inventory or exact branded watch models. Development cards are marked as demos. Actual listings should use the client's own or licensed product photographs.
